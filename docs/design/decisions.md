# Проєктні рішення

## Базові рішення

- Застосунок працює на Windows 10/11 як настільна програма WinForms на .NET.
- Google Drive інтегрується через OAuth 2.0 та офіційну бібліотеку Google Drive API v3.
- Локальні метадані та журнал зберігаються в SQLite.
- Базовий сценарій MVP синхронізує одну пару папок та передає нові/змінені файли у двох напрямках.
- Для подальшого розвитку описано кілька пар папок, маски виключень, конфлікти, трей та автозапуск.

## Рішення, покладені в основу діаграм

1. WinForms викликає окремий координатор синхронізації; інтерфейс не працює напряму з Google API або SQL.
2. FileSystemWatcher дає локальні сигнали, а періодичне сканування локальної та хмарної папки слугує способом звірити стан після пропущених подій.
3. Для зіставлення зберігаються відносний локальний шлях і Google Drive file ID. У SQLite зберігається контрольна інформація, потрібна для виявлення змін.
4. Операції передавання та виклики API асинхронні. Вони повертають результат логіці застосунку для оновлення статусу й журналу.
5. OAuth токен захищається засобом ОС (DPAPI). Таблиці та поля описано в [docs/architecture/data-model.md](../architecture/data-model.md).

## Деталізація

Версія .NET, OAuth scope, спосіб виявлення змін, обробка видалень і конфліктів, інтервал перевірки та строк зберігання журналу визначені в [docs/architecture/decisions.md](../architecture/decisions.md#відповіді-на-відкриті-питання-з-етапу-моделювання).
