# Проєктні рішення та припущення

## Рішення, що прямо спираються на репозиторій

- Застосунок працює на Windows 10/11 як настільна програма WinForms на .NET.
- Google Drive інтегрується через OAuth 2.0 та офіційну бібліотеку Google Drive API v3.
- Локальні метадані та журнал зберігаються в SQLite.
- Базовий сценарій MVP синхронізує одну пару папок та передає нові/змінені файли у двох напрямках.
- Для подальшого розвитку описано кілька пар папок, маски виключень, конфлікти, трей та автозапуск.

## Проєктні припущення для діаграм

1. WinForms викликає окремий координатор синхронізації; інтерфейс не працює напряму з Google API або SQL.
2. FileSystemWatcher дає локальні сигнали, а періодичне сканування локальної та хмарної папки слугує способом звірити стан після пропущених подій.
3. Для зіставлення зберігаються відносний локальний шлях і Google Drive file ID. У SQLite зберігається контрольна інформація, потрібна для виявлення змін.
4. Операції передавання та виклики API асинхронні. Вони повертають результат логіці застосунку для оновлення статусу й журналу.
5. OAuth токен захищається засобом ОС (DPAPI); точні таблиці та схема секретів підлягають технічному узгодженню.

Ці припущення відображають проєктну модель, а не наявний код: у завантаженій копії були документи та зображення схеми, без вихідного WinForms-проєкту.

## Потрібно підтвердити команді

- Які типи та версію .NET і SQLite-провайдера використовувати.
- Які Google Drive scopes достатні для вибраних папок і створення папки.
- Як визначати зміну: хеш вмісту, розмір і дата, `modifiedTime` Drive або їх комбінація.
- Як поводитися з видаленнями та файлами, що заблоковані іншою програмою.
- Яке правило іменування конфліктних копій і чи потрібне ручне підтвердження.
- Чи входить автоматична періодична синхронізація в перший MVP або лише ручний запуск.
- Який діапазон і значення за замовчуванням матиме інтервал опитування.
- Як очищувати журнал і який строк зберігання записів застосувати.

## Межі

Презентація та макети показують запропоновану структуру. Вони не доводять, що OAuth, обмін файлами, конфлікти або фоновий режим уже реалізовані.
