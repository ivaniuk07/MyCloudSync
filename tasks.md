# Пріоритезований перелік завдань

1. Сформувати команду, визначити відповідальність та створити картку проєкту.
2. Визначити заінтересовані сторони.
3. Провести аналіз конкурентів та визначити MVP.
4. Сформувати функціональні та нефункціональні вимоги.
5. Описати історії користувача та критерії приймання.
6. Створити необхідні UML-діаграми (варіантів використання, класів, послідовності для процесу синхронізації).
7. Зареєструвати застосунок у Google Cloud Console та налаштувати доступ до Google Drive API.
8. Спроєктувати локальну базу даних (стан файлів, журнал операцій, налаштування).
9. Розробити макет інтерфейсу.
10. Створити WinForms-проєкт.
