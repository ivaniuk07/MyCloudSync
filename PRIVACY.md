# Політика конфіденційності MyCloudSync

MyCloudSync — настільний застосунок для Windows, який синхронізує вибрану користувачем локальну папку з папкою на його Google Drive. Застосунок створено як навчальний проєкт студентами Львівського національного університету імені Івана Франка.

## Які дані використовує застосунок

- **Адреса електронної пошти та ім'я** акаунта Google — щоб показати, який акаунт підключено.
- **Файли та папки Google Drive** — лише для синхронізації: застосунок отримує список файлів у вибраній папці, вивантажує, завантажує, оновлює файли та переміщує їх у кошик Google Drive.
- **Файли вибраної локальної папки** — для порівняння з хмарною версією та синхронізації.

Застосунок не читає вміст файлів з іншою метою, не аналізує його і не використовує для реклами.

## Де зберігаються дані

Усі дані зберігаються лише на комп'ютері користувача в локальній базі даних `%LOCALAPPDATA%\MyCloudSync\mycloudsync.db`:

- токени доступу Google, зашифровані засобами Windows (DPAPI) для поточного користувача;
- налаштування синхронізації, стан синхронізованих файлів і журнал операцій.

Застосунок не має власного сервера і не передає жодних даних розробникам або третім особам. Обмін даними відбувається лише між комп'ютером користувача та Google Drive.

## Як відкликати доступ

- У застосунку: кнопка «Вийти з акаунта» видаляє токени та налаштування синхронізації з комп'ютера.
- У Google: на сторінці [myaccount.google.com/permissions](https://myaccount.google.com/permissions) можна будь-коли відкликати доступ MyCloudSync до акаунта.

Видалення застосунку разом із папкою `%LOCALAPPDATA%\MyCloudSync` повністю видаляє всі збережені ним дані.

## Використання даних Google

Використання застосунком інформації, отриманої з API Google, відповідає [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), зокрема вимогам Limited Use.
