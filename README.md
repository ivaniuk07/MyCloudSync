# MyCloudSync

**Посилання на репозиторій:** [https://github.com/ivaniuk07/MyCloudSync](https://github.com/ivaniuk07/MyCloudSync)

## Картка проєкту

### Склад команди та відповідальність учасників
* **Іванюк Олексій** - Інтеграція з Google Drive - реєстрація застосунку в Google Cloud Console, авторизація через OAuth 2.0, безпечне зберігання токенів, робота з Google Drive API v3 (завантаження, вивантаження, видалення, отримання списку файлів та змін)
* **Задорожний Максим** - Інтерфейс WinForms - створення головного вікна та вікна налаштувань, вибір папок, іконка в системному треї, відображення статусу синхронізації та журналу операцій
* **Самсін Владислав** - Логіка синхронізації та локальна база даних - відстеження змін у локальній папці (FileSystemWatcher), порівняння локальних і хмарних файлів, двостороння синхронізація, виявлення та вирішення конфліктів; проєктування бази даних SQLite для зберігання стану файлів (шлях, хеш, дата зміни, ID у Google Drive) та журналу операцій

### Проблема
Користувачі часто працюють із файлами на кількох пристроях або хочуть мати резервну копію важливих документів у хмарі. Офіційний клієнт Google Drive для комп'ютера синхронізує весь диск або складну структуру папок, має обмежені налаштування та вимагає постійного контролю. Ручне копіювання файлів у браузері займає час, а користувач може забути вивантажити змінений файл або випадково перезаписати новішу версію старішою.
Програмний продукт MyCloudSync призначений для автоматичної синхронізації однієї або кількох обраних локальних папок у Windows із відповідними папками на прив'язаному акаунті Google Drive.

### Цільові користувачі
* студенти, які зберігають навчальні матеріали та курсові роботи;
* користувачі, які працюють з файлами на кількох комп'ютерах;
* користувачі, яким потрібне автоматичне резервне копіювання важливих папок;
* невеликі команди, що обмінюються файлами через спільний Google Drive.

### Мета
Мета проєкту - розробити настільний застосунок для Windows, який дозволить користувачу прив'язати свій акаунт Google Drive, обрати локальну папку та папку в хмарі, і автоматично підтримувати їх у синхронізованому стані: вивантажувати нові та змінені файли, завантажувати зміни з хмари, коректно обробляти видалення та конфлікти версій.

### Короткий опис основних можливостей
* авторизація та прив'язка акаунта Google Drive через OAuth 2.0.
* вихід з акаунта та відв'язка Google Drive.
* вибір локальної папки для синхронізації.
* вибір або створення папки на Google Drive.
* автоматичне відстеження змін у локальній папці (створення, зміна, перейменування, видалення файлів).
* періодична перевірка змін на Google Drive.
* двостороння синхронізація файлів і вкладених папок.
* виявлення та вирішення конфліктів (збереження обох версій).
* ручний запуск синхронізації та пауза/відновлення.
* робота у фоновому режимі з іконкою в системному треї.
* журнал операцій синхронізації.
* налаштування: інтервал перевірки, режим синхронізації, виключення файлів за маскою, автозапуск з Windows.
* збереження стану файлів у локальній базі даних SQLite.
